FTP - File Transfer Protocol

FTP
File Transfer Protocol is a standard network protocol used for transferring files between a client and a server on a computer network.
It operates on a client-server model and uses separate control and data connections.
FTP is commonly used for uploading files to a web server or downloading files from a remote server.
FTP supports various authentication methods, including anonymous access and user-based authentication.
FTP can be used with different modes of data transfer, such as active and passive modes, to accommodate different network configurations.
