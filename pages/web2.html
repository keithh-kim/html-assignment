Web 2.0
The second generation of the World Wide Web, characterized by user-generated content, social media, and interactive web applications.
Web 2.0 emphasized user participation and collaboration, allowing users to create and share content easily.
It introduced concepts like blogs, wikis, and social networking sites that enabled users to interact and engage with each other.
Web 2.0 transformed the internet from a static information repository into a dynamic platform for communication and social interaction.
